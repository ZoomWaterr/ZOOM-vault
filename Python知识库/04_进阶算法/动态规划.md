# 动态规划

## 一句话抓本质

动态规划不是神秘算法，它的本质是：

> 把大问题拆成小问题，小问题会重复出现，所以先把小问题答案存起来，后面直接拿来用。

更刷题一点说：

```text
递归是“我要这个答案，就去问更小的答案”
DP 是“我从最小答案开始填表，填到题目要的答案”
```

## 先别背 DP 五步，先看重复在哪里

经典例子：爬楼梯。

题意：

> 一共有 n 级台阶，每次能走 1 级或 2 级，问走到第 n 级有多少种方法。

如果 `n = 4`，手算：

```text
走到 4 的方法 =
最后一步从 3 走 1 级上来
或
最后一步从 2 走 2 级上来

所以 ways(4) = ways(3) + ways(2)
```

继续拆：

```text
ways(4)
= ways(3) + ways(2)
= (ways(2) + ways(1)) + ways(2)
```

你看到了吗？

```text
ways(2) 被算了两次
```

`n` 越大，重复越多。

这就是 DP 的入口：

> 有些小问题会反复出现，别傻算，存起来。

参考：HelloAlgo 第 14 章从爬楼梯开始讲 DP，核心也是先看暴力搜索里的重叠子问题，再推到记忆化和表格 DP。

## 三种写法：暴力递归、记忆化、DP 表

### 1. 暴力递归：想法最自然，但重复很多

```python
def ways(n):
    if n == 1 or n == 2:
        return 1
    return ways(n - 1) + ways(n - 2)

n = int(input())
print(ways(n))
```

问题：

```text
ways(5) 会算 ways(4) 和 ways(3)
ways(4) 又会算 ways(3) 和 ways(2)
ways(3) 被重复算
ways(2) 被重复算更多次
```

复杂度接近指数级。

### 2. 记忆化：递归不变，但算过就存

```python
def ways(n, memo):
    if n == 1 or n == 2:
        return 1
    if memo[n] != -1:
        return memo[n]

    memo[n] = ways(n - 1, memo) + ways(n - 2, memo)
    return memo[n]

n = int(input())
memo = [-1] * (n + 1)
print(ways(n, memo))
```

核心：

```text
memo[n] 表示 ways(n) 是否已经算过
算过就直接返回，不再重复递归
```

### 3. DP 表：从小到大填

```python
n = int(input())

dp = [0] * (n + 2)
dp[1] = 1
dp[2] = 1

for i in range(3, n + 1):
    dp[i] = dp[i - 1] + dp[i - 2]

print(dp[n])
```

这里：

```text
dp[i] 表示走到第 i 级台阶的方法数
dp[i] = dp[i-1] + dp[i-2]
```

## DP 表格追踪

`n = 6`：

| i | dp[i-1] | dp[i-2] | dp[i] |
|---:|---:|---:|---:|
| 1 | - | - | 1 |
| 2 | - | - | 1 |
| 3 | 1 | 1 | 2 |
| 4 | 2 | 1 | 3 |
| 5 | 3 | 2 | 5 |
| 6 | 5 | 3 | 8 |

最后：

```text
dp = [0, 1, 1, 2, 3, 5, 8]
```

一句话：

> DP 不是凭空写公式，是你能说清 dp[i] 从哪几个旧格子来。

## DP 五问，必须问得具体

很多人背：

```text
1. 状态
2. 转移
3. 初值
4. 顺序
5. 答案
```

这没错，但太空。要改成这样问：

```text
1. dp[i] 这一个格子到底表示什么？
2. dp[i] 可以从哪几个已经知道的格子推出来？
3. 最小的几个格子是多少？
4. 我填表时，依赖的格子是不是已经填好了？
5. 题目最后要的是 dp[n]、max(dp)，还是 dp[n][cap]？
```

## 例题 1：超级楼梯

常见题意：

> 上楼梯，每次走 1 级或 2 级，问到第 M 级有多少种方法。

变量角色：

| 变量 | 角色 |
|---|---|
| `M` | 目标台阶 |
| `dp[i]` | 到第 i 级的方法数 |
| `dp[1]` | 到第 1 级，1 种 |
| `dp[2]` | 到第 2 级，1 种 |
| `i` | 当前正在填的台阶 |

代码：

```python
T = int(input())

for _ in range(T):
    M = int(input())

    dp = [0] * (M + 2)
    dp[1] = 1
    dp[2] = 1

    for i in range(3, M + 1):
        dp[i] = dp[i - 1] + dp[i - 2]

    print(dp[M])
```

注意：

```text
如果每个测试样例 M 不一样，最稳的方法是每次按 M 开 dp。
如果题目 M 最大值固定，也可以预处理到最大值。
```

## 例题 2：最小路径和

这是 HelloAlgo 第 14 章用来讲 DP 解题思路的典型题。

题意：

> 一个网格里每个格子有代价，从左上走到右下，只能向右或向下，求最小总代价。

小样例：

```text
grid =
1  3  1
1  5  1
4  2  1
```

手算路径：

```text
1 -> 3 -> 1 -> 1 -> 1 = 7
1 -> 1 -> 5 -> 1 -> 1 = 9
其他路径也可以手算对比
最小是 7
```

状态定义：

```text
dp[i][j] 表示从左上角走到 (i,j) 的最小路径和
```

为什么能转移：

```text
到 (i,j) 只能从上面 (i-1,j) 来
或从左边 (i,j-1) 来

所以取更小的那个：
dp[i][j] = min(dp[i-1][j], dp[i][j-1]) + grid[i][j]
```

填表：

```text
grid:
1  3  1
1  5  1
4  2  1

dp:
1  4  5
2  7  6
6  8  7
```

代码：

```python
n, m = map(int, input().split())
grid = [list(map(int, input().split())) for _ in range(n)]

dp = [[0] * m for _ in range(n)]
dp[0][0] = grid[0][0]

for j in range(1, m):
    dp[0][j] = dp[0][j - 1] + grid[0][j]

for i in range(1, n):
    dp[i][0] = dp[i - 1][0] + grid[i][0]

for i in range(1, n):
    for j in range(1, m):
        dp[i][j] = min(dp[i - 1][j], dp[i][j - 1]) + grid[i][j]

print(dp[n - 1][m - 1])
```

这个例子最重要的是：

> `dp[i][j]` 不是随便定义的，它必须能从附近已经算好的格子推出来。

## 例题 3：0-1 背包

这是 DP 入门绕不开的一关，也是 HelloAlgo 第 14 章的重点。

题意：

```text
有 n 个物品，每个物品有重量 w 和价值 v。
背包容量 cap。
每个物品只能选一次。
问最大价值。
```

小样例：

```text
物品1：重量 2，价值 3
物品2：重量 3，价值 4
物品3：重量 4，价值 5
背包容量：5
```

可能选择：

```text
选 1：重2，值3
选 2：重3，值4
选 3：重4，值5
选 1+2：重5，值7  最优
```

状态定义：

```text
dp[i][c] 表示只看前 i 个物品，容量为 c 时的最大价值
```

第 `i` 个物品有两个选择：

```text
不选它：dp[i-1][c]
选它：dp[i-1][c-w] + v
```

所以：

```text
dp[i][c] = max(不选, 选)
```

代码：

```python
n, cap = map(int, input().split())
wgt = []
val = []

for _ in range(n):
    w, v = map(int, input().split())
    wgt.append(w)
    val.append(v)

dp = [[0] * (cap + 1) for _ in range(n + 1)]

for i in range(1, n + 1):
    w = wgt[i - 1]
    v = val[i - 1]
    for c in range(1, cap + 1):
        dp[i][c] = dp[i - 1][c]
        if c >= w:
            dp[i][c] = max(dp[i][c], dp[i - 1][c - w] + v)

print(dp[n][cap])
```

样例输入：

```text
3 5
2 3
3 4
4 5
```

输出：

```text
7
```

## 0-1 背包一维优化：为什么要倒序

二维写熟以后，才看一维：

```python
dp = [0] * (cap + 1)

for i in range(n):
    w = wgt[i]
    v = val[i]
    for c in range(cap, w - 1, -1):
        dp[c] = max(dp[c], dp[c - w] + v)
```

为什么容量要倒序？

```text
0-1 背包每个物品只能选一次。
倒序能保证 dp[c-w] 还是“没选当前物品之前”的旧状态。
```

如果正序：

```python
for c in range(w, cap + 1):
    dp[c] = max(dp[c], dp[c - w] + v)
```

当前物品可能被重复使用，变成完全背包。

一句话：

```text
0-1 背包倒序，完全背包正序。
```

先记住，后面单独开背包专题细讲。

## DP 常见错法

### 错法 1：状态定义太虚

```text
dp[i] 表示答案
```

这不合格。

必须说清：

```text
dp[i] 表示走到第 i 级台阶的方法数
dp[i][j] 表示走到第 i 行第 j 列的最小路径和
dp[i][c] 表示前 i 个物品容量 c 的最大价值
```

### 错法 2：转移用了还没算出来的格子

例如最小路径和：

```text
dp[i][j] 依赖上面和左边
所以填表必须从左上往右下填
```

如果顺序乱了，就会拿到未定义的值。

### 错法 3：初始值没处理边界

最小路径和第一行只能从左边来，第一列只能从上面来。

不能直接套：

```python
dp[i][j] = min(dp[i - 1][j], dp[i][j - 1]) + grid[i][j]
```

因为 `i=0` 或 `j=0` 会越界。

### 错法 4：把递推都叫 DP

不是所有递推都值得叫 DP。

例如普通求和：

```python
s += i
```

这只是累加。

DP 至少要说清：

```text
状态是什么
从哪些状态来
为什么这些旧状态足够
```

## 判断一道题像不像 DP

先看有没有这些信号：

| 信号 | 说明 |
|---|---|
| 最大 / 最小 | 最优值 |
| 多少种方法 | 计数 |
| 每一步有选择 | 决策过程 |
| 当前答案依赖前面答案 | 可递推 |
| 暴力递归会重复 | 适合记忆化 / DP |
| 背包容量、网格坐标、字符串前缀 | 常见状态维度 |

但不要见“最优”就 DP。还要能写出状态。

## DP 解题流程

```text
1. 先写暴力想法：每一步有什么选择？
2. 看重复：哪些小问题被反复算？
3. 定状态：dp[i] 或 dp[i][j] 这一格表示什么？
4. 找来源：这一格从哪些旧格子来？
5. 定初值：最小情况是什么？
6. 定顺序：旧格子必须先算好。
7. 写代码。
8. 用小样例手推 dp 表。
```

## 练习阶梯

1. 手推爬楼梯 `n=6` 的 `dp` 表。
2. 写超级楼梯代码，处理多组输入。
3. 手推最小路径和的 3x3 表。
4. 写最小路径和代码，并解释第一行第一列为什么单独处理。
5. 手推 0-1 背包小样例，写出 `dp[i][c]` 的含义。
6. 对比 0-1 背包倒序和完全背包正序。
