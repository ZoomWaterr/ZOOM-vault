# 快排、归并、堆排序、基数排序

原 PDF 对应页：Algorithm.pdf 第 39-52 页。这里是排序体系里最核心的几类：分治、堆、非比较排序。Python 版要理解思想，也要会写可运行版本。

![快速排序原图](../assets/algorithm/algorithm_p040_01.png)

## 一句话抓本质

快排靠 pivot 分区，归并靠先分后合，堆排序靠维护最大/最小堆，基数排序靠按位分桶。

## 快速排序

```python
def quick_sort(nums: list[int]) -> list[int]:
    arr = nums[:]

    def partition(left: int, right: int) -> int:
        pivot = arr[right]
        store = left
        for i in range(left, right):
            if arr[i] <= pivot:
                arr[store], arr[i] = arr[i], arr[store]
                store += 1
        arr[store], arr[right] = arr[right], arr[store]
        return store

    def sort(left: int, right: int) -> None:
        if left >= right:
            return
        mid = partition(left, right)
        sort(left, mid - 1)
        sort(mid + 1, right)

    sort(0, len(arr) - 1)
    return arr
```

手推 partition：arr = [4, 2, 5, 1, 3]，pivot = 3。

| i | arr[i] | store | 动作 |
|---:|---:|---:|---|
| 0 | 4 | 0 | 4 > 3，不动 |
| 1 | 2 | 0 | 2 <= 3，换到 store |
| 2 | 5 | 1 | 5 > 3，不动 |
| 3 | 1 | 1 | 1 <= 3，换到 store |
| 结束 | - | 2 | pivot 放到下标 2 |

## 归并排序

```python
def merge_sort(nums: list[int]) -> list[int]:
    if len(nums) <= 1:
        return nums[:]
    mid = len(nums) // 2
    left = merge_sort(nums[:mid])
    right = merge_sort(nums[mid:])
    return merge(left, right)

def merge(left: list[int], right: list[int]) -> list[int]:
    i = j = 0
    ans: list[int] = []
    while i < len(left) and j < len(right):
        if left[i] <= right[j]:
            ans.append(left[i])
            i += 1
        else:
            ans.append(right[j])
            j += 1
    ans.extend(left[i:])
    ans.extend(right[j:])
    return ans
```

归并稳定的关键是 left[i] <= right[j] 时先拿 left[i]，相等元素保持原相对顺序。

## 堆排序思维：用 heapq 求前 k 小

Python 的 heapq 是最小堆。真正手写堆排序较少，刷题更常用堆解决 top k。

```python
from heapq import heappop, heappush

def k_smallest(nums: list[int], k: int) -> list[int]:
    heap: list[int] = []
    for x in nums:
        heappush(heap, x)
    return [heappop(heap) for _ in range(min(k, len(heap)))]

print(k_smallest([5, 1, 3, 2, 4], 3))
```

如果要维护前 k 大，可以用大小为 k 的最小堆。

```python
from heapq import heappop, heappush

def top_k_largest(nums: list[int], k: int) -> list[int]:
    heap: list[int] = []
    for x in nums:
        heappush(heap, x)
        if len(heap) > k:
            heappop(heap)
    return sorted(heap, reverse=True)
```

## 基数排序：按个位、十位、百位分桶

只处理非负整数版本：

```python
def radix_sort(nums: list[int]) -> list[int]:
    if not nums:
        return []
    arr = nums[:]
    exp = 1
    max_num = max(arr)
    while max_num // exp > 0:
        buckets = [[] for _ in range(10)]
        for x in arr:
            digit = (x // exp) % 10
            buckets[digit].append(x)
        arr = [x for bucket in buckets for x in bucket]
        exp *= 10
    return arr
```

手推 [170, 45, 75, 90] 第一轮按个位：

| 个位 | 桶 |
|---:|---|
| 0 | 170, 90 |
| 5 | 45, 75 |

收集后变成 [170, 90, 45, 75]，再按十位、百位继续。

## 四类排序对比

| 算法 | 思想 | 优势 | 风险 |
|---|---|---|---|
| 快排 | pivot 分区 | 平均快，原地 | pivot 差会退化 |
| 归并 | 分治合并 | 稳定，最坏稳 | 需要额外空间 |
| 堆 | 每次取堆顶 | top k 好用 | 不稳定 |
| 基数 | 按位分桶 | 可突破比较排序下界 | 依赖数据范围和位数 |

## 常见错法

错误 1：快排 partition 遇到等于 pivot 不移动，重复元素多时可能很慢或死循环。这里用 <= 版本避免二指针卡住。

错误 2：归并 merge 忘记追加剩余部分。

错误 3：top k 大用大根堆全弹，复杂度不必要。维护大小 k 的小根堆更直接。

错误 4：基数排序拿来排负数，没额外处理会错。

## 题目信号

- 大量数据排序：优先内置 sorted。
- 要手写稳定 O(n log n)：归并。
- 平均快、原地：快排。
- 前 k 大/小：堆。
- 非负整数且位数有限：基数或计数排序。
