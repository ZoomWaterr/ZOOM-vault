# 排序总览：稳定性与复杂度

原 PDF 对应页：Algorithm.pdf 第 35-52 页。原文覆盖插入、希尔、冒泡、快排、选择、堆、归并、基数排序，并在最后比较时间、空间和稳定性。Python 版先建立排序地图，再分别练实现。

![排序原图](../assets/algorithm/algorithm_p031_01.png)

## 一句话抓本质

排序算法的差别不只是快慢，还包括是否稳定、是否原地、是否适合近似有序、是否需要额外空间。

## 稳定性是什么

稳定排序：相等 key 的元素，排序后相对顺序不变。

```python
students = [(90, "A"), (80, "B"), (90, "C")]
print(sorted(students, key=lambda x: x[0]))
```

如果按分数排序后 A 仍然在 C 前面，就是稳定。

## 常见排序对比

| 算法 | 平均时间 | 最坏时间 | 空间 | 稳定性 | 备注 |
|---|---:|---:|---:|---|---|
| 直接插入 | O(n²) | O(n²) | O(1) | 稳定 | 近似有序时很好 |
| 希尔 | 取决于 gap | 取决于 gap | O(1) | 不稳定 | 插入排序改进 |
| 冒泡 | O(n²) | O(n²) | O(1) | 稳定 | 可提前结束 |
| 选择 | O(n²) | O(n²) | O(1) | 不稳定 | 交换次数少 |
| 快排 | O(n log n) | O(n²) | O(log n) | 不稳定 | 平均很快 |
| 归并 | O(n log n) | O(n log n) | O(n) | 稳定 | 适合链表/外部排序 |
| 堆排序 | O(n log n) | O(n log n) | O(1) | 不稳定 | 利用堆 |
| 基数排序 | O(d(n+k)) | O(d(n+k)) | O(n+k) | 稳定 | 非比较排序 |

## Python 的 sorted

Python 内置排序是 Timsort，稳定，适合真实工程和大多数刷题。

```python
items = [("apple", 3), ("banana", 2), ("pear", 3)]
items_sorted = sorted(items, key=lambda x: x[1])
print(items_sorted)
```

手写排序的意义不是替代 sorted，而是理解复杂度和边界。

## 怎么判断一个排序是否稳定

用相等 key 的标签测试：

```text
输入：[(2, A), (1, B), (2, C)]
按第一个值排序。
如果输出里 A 仍在 C 前面，则稳定。
```

## 排序题目的常见隐藏要求

| 要求 | 影响 |
|---|---|
| 不能用额外数组 | 归并可能不合适 |
| 要保留相等元素原顺序 | 需要稳定排序 |
| 数据近乎有序 | 插入排序可能很快 |
| 数据范围小 | 计数/基数排序可考虑 |
| 求前 k 大 | 不一定要全排序，可用堆或快速选择 |

## 常见错法

错误 1：只背平均复杂度，忘了快排最坏 O(n²)。有序数组选首元素为 pivot 就容易退化。

错误 2：把“原地”和“稳定”混为一谈。原地说空间，稳定说相等元素顺序。

错误 3：题目只要第 k 大，却全排序。能过但不一定最优。

## 题目信号

- “按多个关键字排序”：稳定性很重要，Python sorted 可以多次稳定排序，也可以 key 返回元组。
- “数据范围 0 到 100”：计数排序可想。
- “只要前 k 个”：堆。
- “链表排序”：归并排序常见。
