## 5.2 哈希表定义

哈希表建立关键字 key 与存储地址 address 的函数关系：

$$
address=H(key)
$$

理想情况下，可以由 key 直接定位记录。

## 5.3 除留余数法

原 PDF 中常用构造方法：

$$
H(key)=key\bmod p
$$

p 通常选小于表长的质数，以减少冲突。

## 5.4 冲突

若：

$$
H(key_1)=H(key_2),\quad key_1\ne key_2
$$

则发生冲突。

常见处理方式：

| 方法 | 思路 |
|---|---|
| 开放定址法 | 冲突后继续探测下一个位置 |
| 链地址法 | 每个槽位挂一条链表 |
| 再哈希法 | 换一个哈希函数继续找 |

## 5.5 Python 中的 dict 与 set

Python 的 dict/set 已经封装了哈希表和冲突处理。

```python
freq: dict[str, int] = {}
for ch in "banana":
    freq[ch] = freq.get(ch, 0) + 1
print(freq)
```

## 5.6 手写链地址法

```python
class HashTable:
    def __init__(self, size: int = 11):
        self.buckets: list[list[tuple[int, int]]] = [[] for _ in range(size)]

    def h(self, key: int) -> int:
        return key % len(self.buckets)

    def put(self, key: int, value: int) -> None:
        bucket = self.buckets[self.h(key)]
        for i, (k, _) in enumerate(bucket):
            if k == key:
                bucket[i] = (key, value)
                return
        bucket.append((key, value))

    def get(self, key: int) -> int | None:
        bucket = self.buckets[self.h(key)]
        for k, value in bucket:
            if k == key:
                return value
        return None
```

## 5.7 装填因子

哈希表效率与装填因子有关：

$$
\alpha=\frac{n}{m}
$$

其中 n 为表中记录数，m 为哈希表长度。alpha 越大，冲突通常越多。

平均复杂度通常认为：

$$
T_{avg}=O(1)
$$

但极端冲突下会退化。
