# 前缀和

## 一句话抓本质

前缀和就是：

> 先把“从开头到每个位置的总和”存起来，以后问一段的和，就用右边总和减掉左边前面的总和。

你原来写的“前缀和就是从头累加”是对的。现在要补上刷题里最关键的两点：

```text
1. 为什么要多开一个 0？
2. 为什么区间和是 prefix[r+1] - prefix[l]？
```

## 先看最小样例

```text
nums:       2   4   1   7   3
下标:       0   1   2   3   4
```

从头累加：

```text
前 0 个数的和：0
前 1 个数的和：2
前 2 个数的和：2+4=6
前 3 个数的和：2+4+1=7
前 4 个数的和：2+4+1+7=14
前 5 个数的和：2+4+1+7+3=17
```

写成数组：

```text
nums:       2   4   1   7   3
下标:       0   1   2   3   4

prefix:  0   2   6   7   14  17
格子号:   0   1   2   3   4   5
```

注意：

```text
prefix[0] = 前 0 个数的和 = 0
prefix[1] = 前 1 个数的和 = nums[0]
prefix[2] = 前 2 个数的和 = nums[0] + nums[1]
```

所以 `prefix` 的格子号和 `nums` 的下标差 1。

## 为什么要多开一个 0

如果没有开头这个 0，查从下标 0 开始的区间会很别扭。

比如查：

```text
nums[0..2] = 2 + 4 + 1 = 7
```

有 `prefix[0] = 0` 时：

```text
prefix[3] - prefix[0] = 7 - 0 = 7
```

公式统一：

```text
sum(l, r) = prefix[r + 1] - prefix[l]
```

不管 `l` 是不是 0，都能用同一个公式。

## 为什么是 `prefix[r+1] - prefix[l]`

查：

```text
nums[1..3] = 4 + 1 + 7 = 12
```

画出来：

```text
nums:       2   4   1   7   3
下标:       0   1   2   3   4
                 [-------]

prefix[4] = nums[0..3] 的和 = 2+4+1+7 = 14
prefix[1] = nums[0..0] 的和 = 2

prefix[4] - prefix[1]
= (2+4+1+7) - 2
= 4+1+7
= 12
```

关键理解：

```text
prefix[r+1]：拿到 r 位置为止的总和
prefix[l]：把 l 左边全部减掉
```

所以剩下的正好是 `[l, r]`。

## 构造前缀和的代码

```python
nums = list(map(int, input().split()))
n = len(nums)

prefix = [0] * (n + 1)

for i in range(n):
    prefix[i + 1] = prefix[i] + nums[i]

print(prefix)
```

输入：

```text
2 4 1 7 3
```

输出：

```text
[0, 2, 6, 7, 14, 17]
```

## 构造过程追踪

| i | nums[i] | prefix[i] | prefix[i+1] |
|---:|---:|---:|---:|
| 0 | 2 | 0 | 2 |
| 1 | 4 | 2 | 6 |
| 2 | 1 | 6 | 7 |
| 3 | 7 | 7 | 14 |
| 4 | 3 | 14 | 17 |

一句话：

> `prefix[i+1]` 就是在 `prefix[i]` 的基础上，加上当前这个 `nums[i]`。

## 完整查询模板

假设输入：

```text
n q
数组
q 行 l r
```

这里用 0 下标，`l r` 都包含。

```python
n, q = map(int, input().split())
nums = list(map(int, input().split()))

prefix = [0] * (n + 1)
for i in range(n):
    prefix[i + 1] = prefix[i] + nums[i]

for _ in range(q):
    l, r = map(int, input().split())
    ans = prefix[r + 1] - prefix[l]
    print(ans)
```

样例：

```text
输入：
5 3
2 4 1 7 3
1 3
0 2
4 4

输出：
12
7
3
```

## 题目如果是 1 下标怎么办

很多 OJ 题目给的是：

```text
第 1 个数到第 3 个数
```

而 Python 列表是 0 下标。

两种写法都可以。

### 写法 A：转成 0 下标

```python
l, r = map(int, input().split())
l -= 1
r -= 1
ans = prefix[r + 1] - prefix[l]
```

### 写法 B：直接用 1 下标前缀和

```python
a = [0] + list(map(int, input().split()))
prefix = [0] * (n + 1)

for i in range(1, n + 1):
    prefix[i] = prefix[i - 1] + a[i]

ans = prefix[r] - prefix[l - 1]
```

如果题目本身就是 1 下标，写法 B 很顺。

## 暴力和前缀和对比

如果有 `q` 次区间查询：

### 暴力

```python
s = 0
for i in range(l, r + 1):
    s += nums[i]
```

复杂度：

```text
一次 O(n)
q 次 O(nq)
```

### 前缀和

```python
ans = prefix[r + 1] - prefix[l]
```

复杂度：

```text
预处理 O(n)
一次查询 O(1)
q 次 O(n + q)
```

前缀和优化的是：

> 不要每次都重新把同一段数字加一遍。

## 两个真实错法

### 错法 1：数组只开 n

```python
prefix = [0] * n

for i in range(n):
    prefix[i + 1] = prefix[i] + nums[i]
```

当 `i = n - 1` 时，`prefix[i + 1] = prefix[n]`，越界。

正确：

```python
prefix = [0] * (n + 1)
```

### 错法 2：公式少了 `+1`

```python
ans = prefix[r] - prefix[l]
```

用样例查 `[1, 3]`：

```text
prefix[3] - prefix[1] = 7 - 2 = 5
正确答案 = 4 + 1 + 7 = 12
```

为什么错：

```text
prefix[3] 只加到 nums[2]
没有包含 nums[3]
```

正确：

```python
ans = prefix[r + 1] - prefix[l]
```

## 什么时候不能只用普通前缀和

前缀和适合：

```text
数组不变，多次查询区间和
```

如果题目是：

```text
数组经常修改，还要经常查询
```

普通前缀和会失效，因为你改一个数，后面所有前缀和都要变。

这种以后再看：

- 树状数组
- 线段树

## 二维前缀和先有个印象

二维前缀和是同一个思想：

```text
一维：从左到右累计
二维：从左上角到当前位置累计一个矩形
```

先把一维彻底吃透，再学二维就不会慌。
