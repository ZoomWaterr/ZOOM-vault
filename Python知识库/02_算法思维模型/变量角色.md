# 变量角色

## 一句话抓本质

变量不是字母，变量是角色。

> 你写不出代码，很多时候不是不会语法，而是不知道每个变量在题里扮演谁。

写算法前先把角色分清，代码才不会乱。

## 最常见的变量角色表

| 变量名 | 常见角色 | 一句话理解 |
|---|---|---|
| `i` | 当前下标 | 我现在处理到哪里了 |
| `j` | 配合比较的另一个下标 | 我拿谁来和 `i` 比 |
| `x` | 当前值 | 当前拿出来的东西 |
| `cnt` | 当前计数 | 当前这一轮数到了几个 |
| `ans` | 最终答案 | 题目最后要输出的东西 |
| `cur` | 当前状态 | 正在累计的临时结果 |
| `pre` / `prev` | 前一个状态 | 上一步是什么 |
| `left` | 左边界 | 当前窗口从哪里开始 |
| `right` | 右边界 | 当前窗口到哪里结束 |
| `visited` | 是否访问过 | 这个点我来过没有 |
| `dp[i]` | 状态答案 | 到第 i 个位置时的答案 |

不要迷信变量名。真正重要的是：

```text
它表示谁？
它什么时候变？
它变成什么？
它是临时的，还是最终的？
```

## 写代码前先填这张表

```text
题目要我求：

输入变量：

循环变量：

临时变量：

答案变量：

每轮更新：

最后输出：
```

这张表比直接敲代码重要。你脑子里没表，代码里就会乱。

## 例题 1：P1428 小鱼比可爱

题意：

> 对每条鱼，数它左边有多少条鱼比它小。

先填变量角色：

| 变量 | 角色 | 什么时候变 |
|---|---|---|
| `n` | 鱼的数量 | 输入后不变 |
| `nums` | 每条鱼的可爱值列表 | 输入后不变 |
| `i` | 当前正在统计的鱼 | 外层循环每轮变 |
| `j` | 当前鱼左边的一条鱼 | 内层循环每轮变 |
| `cnt` | 当前鱼左边比它小的数量 | 每个 `i` 重新从 0 开始 |
| `ans` | 每条鱼的答案列表 | 每完成一条鱼就加一个数 |

代码：

```python
n = int(input())
nums = list(map(int, input().split()))

ans = []

for i in range(n):
    cnt = 0
    for j in range(i):
        if nums[j] < nums[i]:
            cnt += 1
    ans.append(cnt)

print(*ans)
```

## 变量活起来：逐轮看它们怎么变

```text
nums = [4, 3, 0, 5]
```

| 外层 i | nums[i] | 内层 j 走过谁 | cnt 变化 | append |
|---:|---:|---|---|---:|
| 0 | 4 | 空 | 0 | 0 |
| 1 | 3 | j=0, 4<3 False | 0 | 0 |
| 2 | 0 | j=0,1 都 False | 0 | 0 |
| 3 | 5 | 4<5, 3<5, 0<5 | 0 -> 1 -> 2 -> 3 | 3 |

最后：

```text
ans = [0, 0, 0, 3]
```

这里你要抓住一个重点：

> `cnt` 是当前这条鱼的临时答案，`ans` 是所有鱼的总答案。

临时答案每轮要清零，总答案不能清零。

## 例题 2：最长连续递增段

题意：

> 给一串数，求最长连续递增的一段有多长。

例如：

```text
nums = [1, 2, 3, 1, 2, 5, 4]
```

手算：

```text
1 2 3 是一段，长度 3
1 2 5 是一段，长度 3
4 自己一段，长度 1
答案 3
```

变量角色：

| 变量 | 角色 |
|---|---|
| `cur` | 当前连续递增长度 |
| `ans` | 历史最长长度 |
| `i` | 当前检查的位置 |
| `nums[i - 1]` | 前一个数 |
| `nums[i]` | 当前数 |

代码：

```python
n = int(input())
nums = list(map(int, input().split()))

cur = 1
ans = 1

for i in range(1, n):
    if nums[i] == nums[i - 1] + 1:
        cur += 1
    else:
        cur = 1
    ans = max(ans, cur)

print(ans)
```

追踪：

```text
nums = [1, 2, 3, 1, 2, 5, 4]
```

| i | nums[i-1] | nums[i] | 是否接上 | cur | ans |
|---:|---:|---:|---|---:|---:|
| 1 | 1 | 2 | 是 | 2 | 2 |
| 2 | 2 | 3 | 是 | 3 | 3 |
| 3 | 3 | 1 | 否 | 1 | 3 |
| 4 | 1 | 2 | 是 | 2 | 3 |
| 5 | 2 | 5 | 否 | 1 | 3 |
| 6 | 5 | 4 | 否 | 1 | 3 |

这类题最关键的区分：

```text
cur：当前这一段
ans：见过的最好结果
```

很多题都靠这两个角色。

## 例题 3：前缀和里的变量角色

```python
prefix = [0] * (n + 1)

for i in range(n):
    prefix[i + 1] = prefix[i] + nums[i]
```

变量角色：

| 变量 | 角色 |
|---|---|
| `nums[i]` | 当前被加入的数 |
| `prefix[i]` | 前 i 个数的和 |
| `prefix[i + 1]` | 前 i+1 个数的和 |

追踪：

```text
nums:    2   4   1
prefix:  0   2   6   7
格子:    0   1   2   3
```

| i | nums[i] | prefix[i] | prefix[i+1] |
|---:|---:|---:|---:|
| 0 | 2 | 0 | 2 |
| 1 | 4 | 2 | 6 |
| 2 | 1 | 6 | 7 |

这里最容易迷的是 `i` 和 `i+1`。

一句话：

> `nums[i]` 是第 i 个数，`prefix[i+1]` 是把第 i 个数也加进去之后的总和。

## 变量混乱的 5 个危险信号

### 1. 一个变量一会儿当数字，一会儿当列表

```python
ans = 0
ans += 1
ans.append(x)  # 错，数字不能 append
```

解决：

```text
要总数：ans = 0
要列表：ans = []
不要中途换身份。
```

### 2. 临时变量没有重置

```python
cnt = 0
for i in range(n):
    for j in range(i):
        print(i, j)
```

如果 `cnt` 是“当前 i 的计数”，它就必须放进外层循环里面。

### 3. 内外层变量重名

```python
for i in range(n):
    for i in range(m):
        print(i)
```

这样外层 `i` 会被内层覆盖，基本就是自毁。

### 4. 下标和值混在一起

```python
for x in nums:
    print(nums[x])
```

如果 `x` 是值，就不能拿它当下标。

正确要么这样：

```python
for x in nums:
    print(x)
```

要么这样：

```python
for i in range(len(nums)):
    print(nums[i])
```

### 5. 答案变量更新时机错

```python
for i in range(n):
    for j in range(i):
        ans.append(cnt)
```

如果题目是一条鱼一个答案，就必须外层一轮结束后再加入。

## 变量命名小规则

刷题时不用追求英文华丽，追求稳定：

| 场景 | 推荐名 |
|---|---|
| 一组数 | `nums` |
| 当前数 | `x` |
| 数量 | `cnt` |
| 当前连续状态 | `cur` |
| 最终答案 | `ans` |
| 左右边界 | `left`, `right` |
| 行列 | `i`, `j` |
| 图的访问 | `visited` |
| 动态规划表 | `dp` |

## 练习阶梯

1. 给 P1428 代码，在每一行旁边写变量角色。
2. 给 `nums = [3, 1, 4, 2]`，手算每个位置左边有几个更小。
3. 给 `nums = [1, 2, 3, 2, 3, 4, 5]`，手算最长连续递增段。
4. 写一个程序，统计列表里大于平均数的个数，明确 `cnt` 和 `ans` 谁是谁。
5. 写一个程序，输出矩阵每一行的最大值，明确 `i/j/row_max`。

## 验收问题

- `cnt` 和 `ans` 的区别是什么？
- 什么情况下变量要每轮清零？

- `cur` 和 `ans` 为什么经常一起出现？
