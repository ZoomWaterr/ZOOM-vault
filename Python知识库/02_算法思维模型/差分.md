# 差分

## 一句话抓本质

差分就是：

> 不直接改一整段，只在开头和结尾后面打两个标记，最后用前缀和统一还原。

你原来写的这句很关键：

> 差分数组记录的是变化量，前缀和把变化量积累成真实值。

把这句话变成做题动作：

```text
区间 [L, R] 全部 +C
不要真的从 L 加到 R
只做：
diff[L] += C
diff[R+1] -= C
```

## 什么时候想到差分

看到这些题目信号，优先想差分：

| 题目信号 | 翻译 |
|---|---|
| 多次区间加法 | 一段一段批量修改 |
| `[L, R]` 每个位置都加 `C` | 典型差分 |
| 所有操作结束后再输出数组 | 普通差分正合适 |
| 每次操作后不立刻查询 | 可以最后统一还原 |

一句口诀：

> 区间操作就想差分。

## 先看笨办法

数组：

```text
a:      1   2   3   4   5
位置:   1   2   3   4   5
```

操作：

```text
让 [2,4] 每个数 +10
```

笨办法：

```text
a[2] += 10
a[3] += 10
a[4] += 10
```

结果：

```text
a:      1   12  13  14  5
```

如果有很多次操作，每次都从 L 改到 R，就会慢。

## 差分怎么想：只打两个标记

还是这次操作：

```text
[2,4] 每个数 +10
```

差分不直接改原数组，而是想：

```text
从 2 开始，后面都多 10
到 5 开始，后面不再多 10
```

所以：

```text
diff[2] += 10
diff[5] -= 10
```

图：

```text
位置:      1    2    3    4    5    6
diff:      0   +10   0    0   -10   0
                ↑              ↑
              开始多10       从这里取消10
```

对 `diff` 做前缀和：

```text
位置:        1    2    3    4    5
累加变化量:  0   10   10   10    0
```

这说明：

```text
第 2 到第 4 个位置都加 10
第 5 个位置以后不加
```

## 从原数组构造差分

如果原数组是：

```text
a:      1   2   3   4   5
位置:   1   2   3   4   5
```

差分数组表示“当前位置比前一个位置多了多少”：

```text
diff[1] = a[1] - 0    = 1
diff[2] = a[2] - a[1] = 1
diff[3] = a[3] - a[2] = 1
diff[4] = a[4] - a[3] = 1
diff[5] = a[5] - a[4] = 1
```

```text
diff:    1   1   1   1   1
```

对 `diff` 做前缀和可以还原：

```text
1
1+1=2
1+1+1=3
1+1+1+1=4
1+1+1+1+1=5
```

## 完整手算：两次区间修改

初始全 0：

```text
n = 5
a:     0   0   0   0   0
位置:  1   2   3   4   5
```

操作：

```text
1. [2,4] +3
2. [1,3] +2
```

准备差分：

```text
diff:  0   0   0   0   0   0
位置:  1   2   3   4   5   6
```

操作 1：

```text
diff[2] += 3
diff[5] -= 3

diff:  0   3   0   0  -3   0
```

操作 2：

```text
diff[1] += 2
diff[4] -= 2

diff:  2   3   0  -2  -3   0
```

前缀和还原：

| 位置 i | diff[i] | 累加后真实值 |
|---:|---:|---:|
| 1 | 2 | 2 |
| 2 | 3 | 5 |
| 3 | 0 | 5 |
| 4 | -2 | 3 |
| 5 | -3 | 0 |

结果：

```text
a:     2   5   5   3   0
```

手动验证：

```text
先 [2,4]+3 -> 0 3 3 3 0
再 [1,3]+2 -> 2 5 5 3 0
```

对上了。

## 代码模板：初始全 0

输入：

```text
n m
L R C
L R C
后面还有 m 行操作
```

```python
n, m = map(int, input().split())

diff = [0] * (n + 2)

for _ in range(m):
    L, R, C = map(int, input().split())
    diff[L] += C
    diff[R + 1] -= C

for i in range(1, n + 1):
    diff[i] += diff[i - 1]

print(*diff[1:n + 1])
```

样例：

```text
输入：
5 2
2 4 3
1 3 2

输出：
2 5 5 3 0
```

## 代码模板：有初始数组

如果一开始就有数组：

```text
a: 1 2 3 4 5
```

构造差分：

```python
n, m = map(int, input().split())
a = [0] + list(map(int, input().split()))

diff = [0] * (n + 2)

for i in range(1, n + 1):
    diff[i] = a[i] - a[i - 1]

for _ in range(m):
    L, R, C = map(int, input().split())
    diff[L] += C
    diff[R + 1] -= C

for i in range(1, n + 1):
    diff[i] += diff[i - 1]

print(*diff[1:n + 1])
```

## 为什么差分和前缀和是一对

```text
差分：记录变化
前缀和：累加变化，得到真实值
```

类比：

```text
diff 记录每天比昨天多赚多少钱
前缀和算到今天一共赚了多少钱
```

差分本身不是答案。

> 差分只是标记本。前缀和还原后才是真实数组。

## 复杂度对比

假设：

```text
n = 100000
m = 100000
每次修改一段
```

暴力：

```text
每次最坏改 n 个
m 次
O(nm) = 10^10
```

差分：

```text
每次操作只打 2 个标记：O(1)
m 次：O(m)
最后还原：O(n)
总复杂度：O(n + m)
```

## 三个真实错法

### 错法 1：忘记多开空间

```python
diff = [0] * (n + 1)
diff[R + 1] -= C
```

如果 `R = n`，`R + 1 = n + 1`，越界。

正确：

```python
diff = [0] * (n + 2)
```

### 错法 2：只打开始标记，忘记结束标记

```python
diff[L] += C
```

这样从 `L` 开始一直到最后都会加 `C`，不会在 `R` 停下。

正确：

```python
diff[L] += C
diff[R + 1] -= C
```

### 错法 3：把差分数组直接当答案输出

```python
print(*diff[1:n + 1])
```

错在哪里：

```text
diff 是变化量，不是真实值。
必须先前缀和还原。
```

## 普通差分不适合什么

普通差分适合：

```text
一堆区间修改，最后统一输出
```

如果题目要求：

```text
每修改一次，立刻问某个位置或区间的值
```

普通差分就不够，需要以后学：

- 树状数组
- 线段树
