# 总复习与验收题

这个文件不是目录，而是用来检查你到底有没有把两份 PDF 转成 Python 能力。

## 第一层：概念能不能说清

| 问题 | 合格答案必须包含 |
|---|---|
| list 和链表区别是什么 | 随机访问、插入删除、是否连续存储 |
| 栈和队列区别是什么 | LIFO / FIFO，append/pop/popleft |
| DFS 和 BFS 区别是什么 | 数据结构不同，DFS 深入，BFS 分层 |
| BST 为什么中序有序 | 左小根中右大 |
| AVL 旋转保护什么 | 保持 BST 中序顺序，同时降低高度 |
| 哈希表为什么快 | key 映射位置，平均 O(1)，冲突会影响 |
| 快排和归并区别 | 分区 vs 合并，空间和稳定性不同 |
| Dijkstra 不能处理什么 | 负权边 |

## 第四层：错法定位

如果做题错了，先问：

1. 是数据结构选错了吗？比如该用 deque 却用 list.pop(0)。
2. 是下标体系错了吗？比如 PDF 里很多 C 代码用 1 下标，Python 用 0 下标。
3. 是返回值错了吗？Python 失败返回 -1 或 None，不要返回 0。
4. 是边界错了吗？二分到底是闭区间还是半开区间？
5. 是图没建双向边吗？无向图必须 a->b 和 b->a。
6. 是忘了检查不连通或有环吗？MST、拓扑排序都要检查。
7. 是用了不适用的算法吗？负权边不能用普通 Dijkstra。

## 最低通过标准

你不需要一次背完全部代码。最低通过标准是：

- 能解释每个算法解决什么问题。
- 能手推一个 5 个以内元素的小样例。
- 能写出核心 Python 模板。
- 能说出最常见边界条件。
- 能在题目里认出它，而不是只在笔记里认识它。
