# 最短路径、拓扑排序、关键路径

原 PDF 对应页：DataStructure.pdf 第 87-99 页。原文讲 Dijkstra、Floyd、AOV/AOE、拓扑排序和关键路径。Python 刷题里最常用的是 Dijkstra 和拓扑排序，Floyd 用在点数小的全源最短路。

![Dijkstra 原图](../assets/data_structure/data_structure_p088_01.png)

## 一句话抓本质

Dijkstra 是从起点不断确定最近的点；Floyd 是枚举中转点更新任意两点距离；拓扑排序是在有向无环图里按依赖顺序排任务。

## Dijkstra

适用：边权非负。

```python
from heapq import heappop, heappush

def dijkstra(n: int, edges: list[tuple[int, int, int]], start: int) -> list[float]:
    graph = [[] for _ in range(n)]
    for a, b, w in edges:
        graph[a].append((b, w))

    dist = [float("inf")] * n
    dist[start] = 0
    heap = [(0, start)]

    while heap:
        d, u = heappop(heap)
        if d != dist[u]:
            continue
        for v, w in graph[u]:
            nd = d + w
            if nd < dist[v]:
                dist[v] = nd
                heappush(heap, (nd, v))
    return dist
```

变量角色：

| 变量 | 角色 |
|---|---|
| dist[v] | 当前已知 start 到 v 的最短距离 |
| heap | 候选点，距离小的先处理 |
| d != dist[u] | 丢掉过期堆记录 |
| nd | 经过 u 到 v 的新距离 |

## 手推 Dijkstra

边：0->1(2), 0->2(5), 1->2(1), 2->3(2)

| 步骤 | 弹出 | 更新 | dist |
|---|---|---|---|
| 初始 | - | - | [0, inf, inf, inf] |
| 1 | 0 | 1=2, 2=5 | [0, 2, 5, inf] |
| 2 | 1 | 2=3 | [0, 2, 3, inf] |
| 3 | 2 | 3=5 | [0, 2, 3, 5] |
| 4 | 3 | 无 | [0, 2, 3, 5] |

## Floyd

适用：点数较小，需要任意两点最短路。

```python
def floyd(n: int, edges: list[tuple[int, int, int]]) -> list[list[float]]:
    dist = [[float("inf")] * n for _ in range(n)]
    for i in range(n):
        dist[i][i] = 0
    for a, b, w in edges:
        dist[a][b] = min(dist[a][b], w)

    for k in range(n):
        for i in range(n):
            for j in range(n):
                if dist[i][k] + dist[k][j] < dist[i][j]:
                    dist[i][j] = dist[i][k] + dist[k][j]
    return dist
```

Floyd 的核心问题：如果允许经过 k 这个中转点，i 到 j 会不会更短？

## 拓扑排序

适用：有向无环图，任务依赖。

```python
from collections import deque

def topological_sort(n: int, edges: list[tuple[int, int]]) -> list[int] | None:
    graph = [[] for _ in range(n)]
    indeg = [0] * n
    for a, b in edges:
        graph[a].append(b)
        indeg[b] += 1

    q = deque([i for i in range(n) if indeg[i] == 0])
    order: list[int] = []
    while q:
        u = q.popleft()
        order.append(u)
        for v in graph[u]:
            indeg[v] -= 1
            if indeg[v] == 0:
                q.append(v)

    if len(order) != n:
        return None
    return order
```

变量角色：

| 变量 | 角色 |
|---|---|
| indeg[v] | v 还有多少前置任务没完成 |
| q | 当前可以做的任务 |
| order | 拓扑序 |

## 关键路径的直觉

AOE 网里，边表示活动，点表示事件。关键路径是决定总工期的最长路径。某个关键活动延迟，总项目就延迟。

Python 刷题里常见变形：课程安排、任务调度、项目最短完成时间。通常用拓扑排序 + DP 求最长时间。

```python
from collections import deque

def minimum_finish_time(n: int, edges: list[tuple[int, int]], cost: list[int]) -> int | None:
    graph = [[] for _ in range(n)]
    indeg = [0] * n
    for a, b in edges:
        graph[a].append(b)
        indeg[b] += 1

    finish = cost[:]
    q = deque([i for i in range(n) if indeg[i] == 0])
    seen = 0
    while q:
        u = q.popleft()
        seen += 1
        for v in graph[u]:
            finish[v] = max(finish[v], finish[u] + cost[v])
            indeg[v] -= 1
            if indeg[v] == 0:
                q.append(v)
    if seen != n:
        return None
    return max(finish)
```

## 常见错法

错误 1：Dijkstra 用在负权边。负权边会破坏“当前弹出的就是最短”的前提。

错误 2：Floyd 忘记 dist[i][i] = 0。

错误 3：拓扑排序只从 0 开始。入度为 0 的点可能有多个，都要入队。

错误 4：拓扑排序没检查环。order 长度小于 n 就有环。

## 题目信号

- 单源、非负权、最短路：Dijkstra。
- 任意两点、点数小：Floyd。
- 课程依赖、任务先后：拓扑排序。
- 项目工期、最长依赖链：拓扑 + DP。
