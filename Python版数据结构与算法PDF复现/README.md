## 每篇怎么学

每篇都按同一套动作来：

1. 先看“一句话抓本质”，不要先背代码。
2. 看变量角色表，确认每个变量在循环里做什么。
3. 手推小样例，尤其要推下标和边界。
4. 把 Python 代码默写一遍。
5. 看错法对比，知道自己下次最可能错在哪里。
6. 做最后的验收题。
