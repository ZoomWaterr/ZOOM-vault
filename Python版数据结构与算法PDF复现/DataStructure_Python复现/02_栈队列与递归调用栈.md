# 栈、队列与递归调用栈

原 PDF 对应页：DataStructure.pdf 第 19-31 页。原文分别实现顺序栈、链栈、循环队列、链队，并用它们做进制转换、括号匹配和小计算器。Python 里不需要自己 malloc，但必须理解“谁先进谁后出”。

![栈相关原图](../assets/data_structure/data_structure_p023_01.png)

## 一句话抓本质

栈是“最后来的先走”，队列是“先来的先走”；递归本质上就是系统帮你维护的一叠函数调用记录。

## 栈：list 就够用

```python
stack: list[str] = []
stack.append("A")
stack.append("B")
stack.append("C")
print(stack.pop())  # C
print(stack.pop())  # B
```

变量角色：

| 变量 | 角色 |
|---|---|
| stack | 栈本体 |
| append | 入栈 push |
| pop | 出栈 pop |
| stack[-1] | 看栈顶，不删除 |

## 括号匹配

```python
def is_valid_parentheses(s: str) -> bool:
    pairs = {")": "(", "]": "[", "}": "{"}
    stack: list[str] = []
    for ch in s:
        if ch in "([{":
            stack.append(ch)
        elif ch in pairs:
            if not stack or stack[-1] != pairs[ch]:
                return False
            stack.pop()
    return not stack

print(is_valid_parentheses("([]{})"))
print(is_valid_parentheses("([)]"))
```

手推 s = “([)]”：

| ch | stack 变化 | 判断 |
|---|---|---|
| ( | [(] | 左括号入栈 |
| [ | [(, [] | 左括号入栈 |
| ) | 栈顶是 [ | 期待 (，不匹配，False |

这个例子说明：不能只数左右括号数量，还要看嵌套顺序。

## 队列：collections.deque

Python list 的 pop(0) 是 O(n)，队列要用 deque。

```python
from collections import deque

q = deque(["A", "B"])
q.append("C")
print(q.popleft())  # A
print(q.popleft())  # B
```

## 循环队列在 Python 里怎么理解

C 语言循环队列常用 front、rear 和取模，原因是固定数组空间要重复利用。Python 刷题时通常用 deque，不必手写循环数组。但你要理解取模思想。

```python
class CircularQueue:
    def __init__(self, capacity: int):
        self.data = [None] * (capacity + 1)
        self.front = 0
        self.rear = 0
        self.size = capacity + 1

    def is_empty(self) -> bool:
        return self.front == self.rear

    def is_full(self) -> bool:
        return (self.rear + 1) % self.size == self.front

    def push(self, value: int) -> bool:
        if self.is_full():
            return False
        self.data[self.rear] = value
        self.rear = (self.rear + 1) % self.size
        return True

    def pop(self) -> int | None:
        if self.is_empty():
            return None
        value = self.data[self.front]
        self.front = (self.front + 1) % self.size
        return value
```

## 递归调用栈

递归不是魔法。每调用一次函数，系统就压入一层记录。

```python
def factorial(n: int) -> int:
    if n == 1:
        return 1
    return n * factorial(n - 1)

print(factorial(4))
```

手推：

| 调用层 | 等待什么 |
|---|---|
| factorial(4) | 等 4 * factorial(3) |
| factorial(3) | 等 3 * factorial(2) |
| factorial(2) | 等 2 * factorial(1) |
| factorial(1) | 返回 1 |

返回时从最深层开始弹栈：1 -> 2 -> 6 -> 24。

## C 写法到 Python 写法

| C 语言笔记 | Python 写法 | 本质 |
|---|---|---|
| top 指针 | list 的末尾 | 栈顶位置 |
| base 数组 | list | 存栈元素的容器 |
| EntryQ / OutQ | append / popleft | 入队和出队 |
| front、rear 取模 | deque 或手写循环队列 | 避免数组搬移 |

## 常见错法

错误 1：队列用 list.pop(0)。小数据没感觉，大数据会超时。

```python
def slow_queue_demo(values: list[int]) -> list[int]:
    q = values[:]
    out = []
    while q:
        out.append(q.pop(0))
    return out
```

错误 2：递归忘记终止条件。

```python
def bad_countdown(n: int) -> int:
    if n == 0:
        return 0
    return bad_countdown(n - 1)
```

这段有终止条件。如果把 if n == 0 删除，就会无限递归直到 RecursionError。

## 题目信号

- 最近的、匹配的、撤销操作：想栈。
- 层次遍历、最短步数、扩散：想队列。
- 自相似结构、树、DFS：想递归或手动栈。
